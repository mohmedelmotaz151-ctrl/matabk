# مطبّك — Multi-user + Motion Sensor + Android/Google Play

## الجديد
- حساس حركة يعتمد على `DeviceMotionEvent` (accelerometer) مع `deviceorientation` كإشارة مساعدة.
- معايرة تلقائية لمحور الجاذبية لتقليل اختلاف وضع الهاتف.
- عند رصد صدمة مفاجئة قوية أثناء القيادة يظهر سؤال: «هل كانت مطبًا/حفرة؟».
- إذا لم يرد السائق خلال 8 ثوانٍ، تُضاف تلقائيًا: اتجاه الصدمة للأعلى = مطب، واتجاهها للأسفل = حفرة.
- المطبات والحفر مشتركة عبر Supabase/PostgreSQL/PostGIS.
- الحقل `source` يميز الإضافة اليدوية عن الإضافة التلقائية بالحساس.

## ملاحظة مهمة عن الحساس
الـ Gyroscope يقيس الدوران، بينما الـ Accelerometer هو الحساس الأساسي لاكتشاف الصدمة/التسارع. لذلك التطبيق يجمع بين الاثنين بدل الاعتماد على الجيروسكوب وحده.
أفضل نتيجة تحتاج تثبيت الهاتف جيدًا في حامل السيارة. لا يمكن للحساس معرفة «أعلى/أسفل الطريق» بدقة مطلقة إذا كان الهاتف متحركًا أو ممسوكًا باليد؛ لهذا التصنيف احتمالي ويجب تأكيد البيانات مجتمعيًا.

## تشغيل الويب
1. أنشئ Supabase.
2. شغّل `supabase/schema.sql`.
3. فعّل Email/Password.
4. انسخ `.env.example` إلى `.env` وضع URL و anon key.
5. `npm install`
6. `npm run dev`

## Google Play / Android
هذا المشروع مجهز بـ Capacitor. بعد تثبيت Node.js وAndroid Studio:

```bash
npm install
npm run build
npx cap add android
npx cap sync android
npx cap open android
```

في Android Studio:
- اختبر التطبيق على جهاز حقيقي لأن الحساسات لا يمكن تقييمها جيدًا بالمحاكي.
- أنشئ `Signed App Bundle (AAB)`.
- ارفع ملف AAB إلى Google Play Console.
- أضف سياسة خصوصية تشرح استخدام الموقع والحساسات.
- صرّح عن بيانات الموقع في نموذج Data Safety وفق ما يجمعه التطبيق فعليًا.
- اختبر الأذونات، الإشعارات، وإيقاف التطبيق وإعادة تشغيله.

## مهم للسلامة وGoogle Play
التنبيه بالحساس ليس ضمانًا لاكتشاف كل مطب أو حفرة. لا ينبغي أن يعتمد السائق على التطبيق وحده، ويجب ألا يتطلب التفاعل مع الهاتف أثناء القيادة.
الإضافة التلقائية بعد عدم الرد صُممت لتقليل تفاعل السائق، لكنها قد تنتج أخطاء؛ لذلك يحتفظ النظام بدرجة ثقة وتصويتات المجتمع ويمكن للإدارة مراجعتها.

## قبل النشر النهائي
- إضافة خدمة خلفية/Edge Function للاستعلام الجغرافي حسب المسار واتجاه السير.
- إضافة صلاحيات مدير فعلية في RLS بدل الاعتماد على الواجهة.
- إضافة rate limiting ومكافحة الحسابات الوهمية.
- إضافة سجل تدقيق وحذف آمن للبيانات.
- تحسين خوارزمية كشف الصدمات باستخدام بيانات الطريق والسرعة والاتجاه.
- إضافة اختبارات على عدة أجهزة وحوامل سيارات.
