# مطبّك 🚗⚠️

نسخة MVP فعلية تعمل مباشرة في المتصفح. التطبيق يعرض خريطة، يحدد موقع المستخدم، ويتيح إضافة المطبات وتأكيدها وتعديل بياناتها، مع وضع قيادة وتحذير صوتي.

## التشغيل
لا يحتاج المشروع إلى Node.js.

- افتح `index.html` مباشرة في المتصفح، أو ارفعه إلى GitHub Pages / Vercel.
- للسماح بـ GPS والصوت، يفضل تشغيله عبر HTTPS (مثل GitHub Pages أو Vercel).

## المزايا الحالية
- خريطة OpenStreetMap عبر Leaflet.
- تحديد الموقع GPS.
- وضع القيادة.
- قراءة سرعة الجهاز عندما يوفرها GPS.
- حساب المسافة إلى أقرب مطب.
- تحذير صوتي تدريجي.
- كتم/تشغيل الصوت.
- إضافة مطب من موقع المستخدم.
- تفاصيل المطب.
- تأكيد وجود المطب أو الإبلاغ عن عدم وجوده.
- تعديل نوع وشدة المطب.
- حفظ البيانات محليًا في LocalStorage.

## الرفع على GitHub
ارفع الملفات الثلاثة:
- `index.html`
- `style.css`
- `app.js`

ثم من إعدادات المستودع فعّل **GitHub Pages** واختر الفرع `main` والمجلد `/root`.

## التطوير التالي
النسخة الحالية MVP ببيانات محلية. لإطلاق نسخة متعددة المستخدمين يجب إضافة Backend وقاعدة بيانات جغرافية (PostgreSQL + PostGIS أو Firebase)، حسابات مستخدمين، نظام ثقة، مزامنة المطبات، وواجهة إدارة.

## السلامة
التطبيق مساعد فقط ولا يجب الاعتماد عليه وحده أثناء القيادة. GPS قد يخطئ، وبيانات المطبات قد تكون غير مكتملة. يجب مراقبة الطريق والالتزام بالأنظمة المرورية.
